# Changelog

All notable changes to Callora are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/) and uses semantic versioning.

## [0.1.0] — 2026-10-24

### Added
- Initial functional Android application (Kotlin, Jetpack Compose, Material 3).
- Subscription discovery, per-SIM configuration and dual-SIM-safe identity handling.
- GSM MMI builder and user-confirmed dialer handoff; manual/unsupported backends.
- Forwarding state machine, provenance tracking, operation coordinator, retry policy.
- Bangladesh operator capability registry with evidence records.
- Room database, DataStore settings, WorkManager recovery and scheduling.
- Onboarding, dashboard, SIMs, profiles, schedules, history, settings, about, troubleshooting.
- English and Bengali localization; adaptive vector launcher icon.
- Unit/Robolectric tests, Compose UI tests, GitHub Actions CI and release workflow.
